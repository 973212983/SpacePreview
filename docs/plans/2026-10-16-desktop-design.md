# 原生桌面界面调整

用户选择简洁、克制的桌面风格，并指定参考 Flow Launcher 的设置页截图：左侧分类导航，右侧设置卡片。启动界面只做使用引导。

- 启动界面仅介绍选中文件、按预览快捷键、关闭预览三个步骤；没有文件选择按钮或示例列表。
- 使用系统字体、中性色与单一蓝色操作强调，保持 36px 预览标题栏和原有文件操作。
- 左栏包含使用指南、设置、关于与更新三个入口；设置页合并应用主题、窗口与启动、预览快捷键和常用操作。右栏独立滚动，设置开关以卡片呈现；更新通知直接进入关于与更新。
- 浅色、深色、跟随系统，以及最小桌面尺寸 640×480 均需验证。
- 用户选定第三版抽象 S 图标。符号源稿为 `assets/app-icon-concept.png`，桌面图标源稿为 `assets/app-icon.png`（加浅色底以适配深色任务栏），已接入页面、favicon 和 Windows/macOS 图标。
- 图标生成：`npm run tauri -- icon assets/app-icon.png --output <临时输出目录>`，取桌面所需 PNG、ICO、ICNS 文件复制到 `src-tauri/icons`；256px PNG 用于 `public/app-icon.png`。

验证：`scripts/smoke-desktop-design.mjs` 覆盖无文件选择入口、三个分类与合并设置、图标加载、主题、小窗口和预览/设置切换；现有偏好、快捷键与更新测试负责行为回归。截图保存在忽略目录 `test-results`。
