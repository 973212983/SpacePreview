# 渐进文档与文件夹预览

- 更多格式采用同一使用方式：小文件直接加载，大文本超过 512 KiB 后先读 64 KiB，再逐步扩大前缀；CSV 只发布完整记录，解码保留跨段字符边界。HTML 保留原有安全过滤与样式，并恢复滚动位置。
- XLSX、EPUB、PPTX 文本预览超过 1 MiB 后读取 ZIP 索引与必要元数据，再按工作表、章节、幻灯片发布；不读取未使用媒体。OpenDocument 和旧工作簿在完整结构解析后分批交付正文或工作表。已有内容在后续失败时保留，文件切换取消任务。
- 加载中明确标记当前只显示已加载内容；完成后仍使用原有全文、目录与表格交互。PDF 和音视频沿用现有按需读取。依赖整包解码或原生转换的格式不强行切断字节；保留原有格式容量限制。

- DOCX 保持原始排版。先读取 ZIP 目录与结构 XML，沿用现有安全校验和主题字体处理；图片与嵌入字体按渲染请求顺序读取。原始页面分批挂载，图片未就绪时也可阅读，加载进度不遮挡页面。切换文件会取消读取和解析任务。
- 此方案仍需先解析正文 XML，不能承诺任意超大纯文字文档瞬时首屏。RTF、旧版 DOC 及其他 Office 引擎不宣称已实现流式排版。
- 文件夹通过 Explorer/Finder 选中后使用现有预览键打开，也支持原生拖入与启动参数。左侧目录树每次只读当前层，每批 500 项，按需展开，右侧使用现有预览组件。目录授权为精确路径，不递归授权整个磁盘；不跟随越出当前目录的链接。
- 不支持类型显示整页提示，提供文件名、原因、默认应用打开及文件信息入口。系统选择错误和文件读取失败不再仅用 toast 提示；Esc 或预览键关闭。

验证：新增 smoke-progressive-directory.mjs 验证暂停图片读取时原排版首屏可用、图片最终加载、切换取消、未引用资源不读取、整页提示、目录按需展开/分页/空目录/权限错误/键盘。已有 smoke-reading.mjs 验证 DOCX 字体、表格、图片、分页与导航。原生测试覆盖目录只读当前层、分页无重叠以及拒绝将文件夹读作文件。
